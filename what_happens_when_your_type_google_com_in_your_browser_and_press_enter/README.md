# What Happens When You Type google.com

Understanding the web stack infrastructure when you type a URL in your browser.

## Requirements

Write a blog post and create a diagram explaining what happens when you type `https://www.google.com` in your browser and press Enter.

Your blog post must cover:
- DNS request
- TCP/IP
- Firewall
- HTTPS/SSL
- Load-balancer
- Web server
- Application server
- Database

## Tasks

- **0-blog_post** - URL to your published blog post (Medium or LinkedIn)
- **1-what_happen_when_diagram** - URL to your diagram showing the request flow
